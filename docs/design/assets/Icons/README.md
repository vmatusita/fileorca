# Ícones

39 ícones próprios, grade de 24×24, traço 2px, pontas e cantos redondos. Estes arquivos têm o traço em Orca `#0F1B2D`, para uso em `<img>`. No site, use a versão inline com `stroke="currentColor"`, `class="fo-icon"` (24px) ou `fo-icon fo-icon--sm` (20px) e `aria-hidden="true"`: é o mesmo desenho, só troca o atributo `stroke`.

- Arquivo e mídia: file, image, pdf, upload, download, paste, trash.
- Ferramentas: compress, resize, crop, rotate, convert, merge, split, lock, unlock, qr, sign, watermark, page-number, reorder (os quatro últimos desenhados na F5a, DECISOES § 149).
- Calculadoras e áreas: calculator, home, heart, table, sparkline, link.
- Interface: search, globe, shield, check, alert, info, close, chevron-down, chevron-right, arrow-right, coffee, offline.

Ícone sozinho só em ação de linha, com `aria-label` no botão. Ferramenta que pede um ícone que não existe (assinar, marca d'água, carro, cartão…) ganha um desenhado na mesma grade e no mesmo traço, que entra aqui com decisão registrada no DECISOES.md.
