FileOrca UX v2 · protótipos da F10

Cada protótipo é uma página HTML estática sobre o design system (docs/design/) e o proto.css desta pasta. Para abrir, dê um duplo clique no arquivo (ele abre por file://) ou sirva a raiz do repositório com qualquer servidor estático e abra /docs/propostas/ux-v2/index.html. Dentro de cada protótipo, o bloco "Prototype control", acima da página, troca o estado, o idioma e o tema; na URL, o mesmo vale por ?state=, ?lang=pt ou ?lang=es e ?theme=dark (na parede, ?modo=). A especificação de cada peça fica abaixo da página.

Os itens, o diagnóstico, as pendências e o mapa de anúncios estão no README; a lista para marcar é o ESCOLHAS.md (copie para .cache/ESCOLHAS-marcado.md e marque lá). As capturas do diagnóstico ficam em docs/relatorios/fase-10/diagnostico/.
